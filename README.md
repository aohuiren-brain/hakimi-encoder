# 说东道西编码转换器 - 图片加密版

一个功能强大的多进制编码转换和图片隐写加密工具，支持文本编码、图片加密和AES加密保护。

## 🌟 功能特性

### 文本编码功能
- **多进制支持**：2-16进制自定义编码
- **字符映射**：支持任意字符集作为编码基础
- **AES加密**：可选密钥保护，增强安全性
- **实时预览**：字符映射关系实时显示

### 图片加密功能
- **LSB隐写技术**：将文本隐藏在图片像素中
- **视觉无损**：对原图质量影响极小
- **大容量存储**：支持存储大量文本数据
- **密钥保护**：AES加密确保数据安全
